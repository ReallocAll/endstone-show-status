# endstone-show-status v0.2.7

Invalid configuration prevents activation before network/thread/task startup. Chat capture observes final Endstone cancellation and excludes asynchronous or recipient-restricted events. Basic Auth supports UTF-8 credentials. Servers with later Script API moderation must keep expose_chat=false.

Validation: automated regression tests and wheel validation. No real BDS runtime or power-loss/crash-kill validation was performed for this refactor. Existing configuration and data should be backed up before upgrading.

Installation: stop the server, activate its current Python environment, then run `uv pip install --upgrade ./endstone_show_status-0.2.7-py3-none-any.whl`. Restart the server. Do not copy this wheel into plugins; install it into the environment used by Endstone.
