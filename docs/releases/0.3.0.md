# endstone-show-status v0.3.0

The plugin now exclusively implements the TPS/MSPT/PING in-game HUD and player settings form. The embedded public HTTP server, dashboard, and JSON protocol have moved to the independent [endstone-status-api](https://github.com/ReallocAll/endstone-status-api) project with a new API contract.

The existing per-player `player_settings.json` remains supported. The new `hud.toml` controls the global switch and default HUD interval; previous `config.toml` is not used and remains on disk for manual reference.

Install the wheel into the Python environment used by Endstone. Both plugins can be installed independently.
